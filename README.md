# Cloudflare Pages Парсер с Puppeteer & D1

Привет! Я полностью обнулил проект, удалил конфигурации Wrangler, чтобы Cloudflare дал тебе **полный ручной контроль через веб-интерфейс**. Никаких блокировок настроек в UI!

В этом проекте:
* `/public` - Фронтенд на чистом JS и Tailwind.
* `/functions/api` - Серверная часть (Pages Functions), которая сама запускает Chrome (Puppeteer API).
* Логирование каждого микро-действия для легкой отладки (всё выводится прямо на веб-странице).

## Инструкция по ручной настройке (Деплой 100% через Cloudflare Dashboard)

### Шаг 1. Загрузка в GitHub
Просто запуш этот код к себе в GitHub (как ты уже и сделал, в репозиторий `parser`). Обрати внимание, что файл `wrangler.toml` полностью удалён – это и есть секрет разблокировки UI панелей.

### Шаг 2. Создание проекта Pages (с нуля)
1. Открой Cloudflare -> **Workers & Pages**.
2. **Внимание!** Убедись, что твой аккаунт переведен на **Workers Paid план ($5/мес)**. Browser Rendering API (Puppeteer) не работает или очень сильно ограничен по длительности сессий на бесплатном тарифе (выдает `Browser.getVersion timed out`).
3. Нажми **Create application** -> вкладка **Pages** -> **Connect to Git**.
4. Выбери репозиторий `parser` -> **Begin setup**.
5. Заполни настройки сборки:
   * **Framework preset:** `None`
   * **Build command:** `npm run build` (или пусто - скрипт просто есть в package.json и ничего лишнего не делает)
   * **Build output directory:** `public`
6. Нажми **Save and Deploy**. (Первый деплой завершится, но сайт выдаст ошибки подключения к БД/браузеру – это нормально, мы сейчас привяжем их вручную).

### Шаг 3. Ручная привязка D1 Database
1. Зайди в главное меню Cloudflare -> **Storage & Databases** -> **D1 SQL Database**. Создай базу, назови её `price_history`.
2. Прямо у только что созданной базы есть вкладка **Console**, скопируй туда SQL-код из файла `schema.sql` и выполни.
3. Вернись в твой Pages проект (`parser`) -> перейди на вкладку **Settings**.
4. Перейди в раздел **Bindings** (обрати внимание, теперь он полностью разблокирован для ручного ввода!).
5. Нажми **Add** -> выбери **D1 database**.
   * Variable name: `DB` *(Обязательно большими буквами!)*
   * D1 database: Выбери твою базу `price_history`

### Шаг 4. Ручная привязка Browser Rendering API
Там же в разделе **Bindings** (в настройках проекта Pages):
1. Опять нажми **Add** -> выбери **Browser Rendering**.
2. Поле **Variable name** укажи строго: `MYBROWSER`

### Шаг 5. Применение настроек (Re-deploy)
Чтобы новые привязки (`DB` и `MYBROWSER`) вступили в силу, Cloudflare требует пересобрать проект!
1. Зайди на вкладку **Deployments** в твоем проекте Pages.
2. У последнего успешного билда нажми три точки справа -> **Retry deployment**.
3. Дождись завершения.

Всё! Теперь открывай домен `https://parser.pages.dev/`. Запускай тест.
В интерфейсе справа вверху есть датчики статуса D1 и PUPPETEER. Если они зелёные ("READY / CONNECTED") - всё настроено идеально. Весь лог действий бразуера теперь будет сыпаться в окно консоли на сайте.
